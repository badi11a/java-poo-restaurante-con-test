# Proyecto Restaurante - Pruebas Unitarias (JUnit 5)

Proyecto de referencia para aprender Arquitectura en Capas y testing con JUnit 5 usando Maven.

## Instrucciones para Estudiantes

1. Clona o descarga este repositorio.
2. Abre **únicamente la carpeta raíz** en Visual Studio Code (`File > Open Folder...`).
3. Ve a la vista de extensiones y asegúrate de tener instalado el **Extension Pack for Java**.
4. Espera unos segundos para que VS Code lea el archivo `pom.xml` y descargue las dependencias.
5. Ve a `src/test/java/cl/td/restaurante/RestauranteTest.java`.
6. Presiona el botón **Run Test** que aparece sobre el código o usa el panel lateral de "Testing" (ícono de matraz).
